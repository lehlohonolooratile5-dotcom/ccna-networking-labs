# ccna-networking-labs

## What it does
A collection of hands-on networking labs completed as part of 
CCNA 1 (Introduction to Networks) and CCNA 2 (Switching, Routing, 
and Wireless Essentials), covering switch configuration, VLANs, 
routing protocols, and subnetting.

## What I used
Cisco Packet Tracer for network simulation and configuration, 
Wireshark for traffic analysis and monitoring.

## What I learned
Practical configuration of switches and routers, VLAN 
segmentation, subnetting calculations, and diagnosing 
connectivity issues through packet analysis.
